# Version 1.0 Requirement Archive

## Purpose

This directory preserves the requirements released with Mini Server v1.0.0.

These files are historical records of the v1.0 contract. They must not later be rewritten to describe v1.1 behavior; changes to released behavior require new requirements.

## Release

- Version: `v1.0.0`
- Release date: 2026-08-15
- Release tag: `v1.0.0`

## Released Requirements

- REQ-001 — Static File Serving
- REQ-002 — Dynamic Port Allocation
- REQ-003 — JSON Persistence API
- REQ-004 — JavaScript Client API
- REQ-005 — Example Application and Template Package
- REQ-006 — Startup, Browser Launch, and Server Lifetime
- REQ-007 — Error Handling and File Permissions
- REQ-008 — Runtime and Distribution

All 182 acceptance criteria from these requirements were verified before release. The final evidence is recorded in `docs/notes/V1.0-RELEASE-VERIFICATION.md`.
