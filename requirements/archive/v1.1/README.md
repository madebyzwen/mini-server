# Version 1.1 Requirement Archive

## Purpose

This directory is the future archive location for requirements released with Mini Server v1.1.

## Current State

Mini Server v1.1 has not been released.

REQ-009 and REQ-010 are currently active and authoritative under `requirements/active/`. No v1.1 requirement is archived here yet.

Requirements may move into this directory only after v1.1 is actually released. Once archived, they become historical release records and should not later be rewritten to describe newer behavior.
