Developer reference

Use MiniApi from any application

Include the shared script. MiniApi derives the first application path segment automatically, handles JSON transport, and requires an explicit scope after every operation. 

<script src="/_shared/mini-api.js"></script>
  • Operation comes first; .shared() or .private() is mandatory.
  • Pass native JavaScript objects and arrays directly to write.
  • Shared and private scopes use separate persistence files.
  • Access persistence through MiniApi, never by requesting data.json.
MiniApi.read("section").shared()
MiniApi.read("section").private()

MiniApi.readAll().shared()
MiniApi.readAll().private()

MiniApi.write(data).shared()
MiniApi.write(data).private()

MiniApi.remove("section").shared()
MiniApi.remove("section").private()

MiniApi.clear().shared()
MiniApi.clear().private()
