# Release v1.1

## Status

Planned

## Purpose

Mini Server v1.1 is the next planned minor release after v1.0.0.

It changes only the browser-selection and automatic start-site behavior approved for v1.1. The released v1.0 runtime, persistence, API, routing, and shutdown behavior remains unchanged except where the active v1.1 requirements explicitly modify startup/browser behavior.

## Approved Requirements

The complete approved v1.1 functional scope is:

- REQ-009 — Default Browser Launch
  - Mini Server asks Windows to open local application URLs through the configured operating-system HTTP URL handler instead of selecting Microsoft Edge.
- REQ-010 — Configurable Start Sites
  - Shared installation configuration approves which existing applications are eligible for automatic opening and defines their order. Private current-user configuration may reduce that selection but cannot elevate an application outside Shared or reorder it.

Both requirements are active under `requirements/active/` and target v1.1.

The v1.1 distribution is planned to include `example` as the default active entry in the Shared `<installation-root>\config\start-sites.txt`. The application is not hard-coded in Java and opens only when it is in the effective selection.

Private selection belongs to the current Windows user at `%APPDATA%\MiniServer\config\start-sites.txt`. The release ZIP does not package a pre-created Private file. When Private is missing, the complete valid Shared selection is effective; when Private exists, only its subset of the valid Shared selection is effective in Shared order.

## Planned Tasks

The approved implementation and verification order is:

1. T-015 — Implement Default Browser Launch
2. T-016 — Implement Configurable Start Sites
3. T-017 — Verify v1.1 Release Scope

## Compatibility Boundary

The following v1.0 behavior remains authoritative unless REQ-009 or REQ-010 explicitly changes it:

- Loopback-only binding to `127.0.0.1`
- Operating-system-assigned dynamic ports
- Local per-user/computer single-instance coordination
- Detached `javaw.exe` startup
- Authenticated graceful `stop.bat` shutdown
- Static multi-application serving
- Shared and private JSON persistence
- MiniApi and persistence concurrency behavior
- Browser-independent server lifetime

## Scope Boundary

No additional v1.1 feature is approved by this document. New functionality requires its own approved requirement and must not be inferred from planning notes or roadmap ideas.

The earlier default-browser and configurable-start-sites notes remain historical planning context. REQ-009, REQ-010, the current architecture, and approved decisions are authoritative if those notes differ.

## Release Verification

Version 1.1 must not be marked ready or released until T-017 verifies every active v1.1 acceptance criterion or explicitly records any incomplete criterion. A known incomplete required criterion prevents release readiness.
