# Release v1.1

## Status

Planning

## Planning State

Mini Server v1.1 is in planning. No v1.1 requirement has yet been approved, and this document is not an implementation contract.

Candidate ideas must pass through the normal requirements workflow before they become binding. No v1.1 implementation task should be created until its corresponding requirement has been explicitly reviewed and approved.

## Current Planning Candidates

The current planning material consists of two non-binding notes:

- [Default Browser Launch](../docs/notes/V1.1-DEFAULT-BROWSER.md) — candidate to ask Windows to open Mini Server URLs with the user's configured default browser instead of hard-coded Microsoft Edge selection.
- [Configurable Start Sites](../docs/notes/V1.1-START-SITES.md) — candidate to optionally configure which existing Mini Server applications are opened automatically at startup.

These summaries identify planning candidates only. They do not approve either feature, define final behavior, select implementation details, or expand the released v1.0 contract.

## Scope Boundary

No v1.1 requirement or implementation task exists yet. Architecture and technical decisions remain unchanged until an approved requirement makes an update necessary.

The existing planning notes remain the detailed source for the candidate ideas. They must not be treated as approved requirements merely because they are referenced by this planning document.
