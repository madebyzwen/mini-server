## Purpose

Version 1.0 is the first functional release of Mini Server.

It provides the complete initial Java implementation for lightweight local or trusted internal web applications while preserving the project's intentionally small core concept.

## Target Environment

The released version targets:

- Windows
- Java 8 compatible runtime
- Microsoft Edge
- Local loopback operation through `127.0.0.1`

The server is not intended for public internet use.

## Released Functionality

Version 1.0 provides:

- A lightweight Java-based HTTP server compatible with Java 8
- Static file serving from the editable `www/` directory
- Multiple independent web applications below one shared web root
- Automatic allocation of an operating-system-selected local TCP port
- Loopback-only binding to `127.0.0.1`
- Local per-user/computer single-instance coordination for shared or local installations
- Detached Windows startup through `start.bat` and `javaw.exe`
- Graceful local shutdown through `stop.bat`
- Automatic Microsoft Edge launch with the active server URL
- A central JSON persistence API with explicit shared and private scopes
- Namespace and filesystem separation for per-application persistence
- Concurrency-safe persistence writes using bounded file locking and atomic replacement
- A shared `mini-api.js` browser library using native JavaScript values
- A working example application
- A reusable application template distributed as `miniweb-template.zip`
- Predictable, path-safe error handling and concise transient diagnostics
- Operation without administrator privileges, a database, or separate server software
- Automated CI and semantic release workflows
